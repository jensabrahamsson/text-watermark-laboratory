\begin{abstract}
With matched labeled marked and unmarked reference generations, and with
detector keys withheld at scoring time, empirical next-token count tables
rank held-out prompt-group means on Google DeepMind's public SynthID-Text
instance (\texttt{public-deepmind-30}). Exploratory in-domain ranking is
\textbf{36/36} families (hits reader; file AUC $0.930$). Under a
predeclared leave-one-family-out protocol on 100 new GPT-2 families, lock~A
Witten--Bell interpolate ranking is \textbf{99/100} (mean paired difference
$0.520$; the single miss is stem 088). The corrected original 12-family
hard-reader diagnostic is \textbf{9/12} group wins.

These group successes are not standalone file detection. On the original
96 files the prespecified zero threshold yields 25 true positives, 23 false
negatives, 22 true negatives, and 26 false positives: sensitivity
\textbf{25/48}, specificity \textbf{22/48}, and
\textbf{47/96} correct decisions ($48.96\%$ balanced accuracy).
Threshold-free file AUC is $0.590$. The official keyed detector still
separates leftover files that the empirical reader cannot decide from
observed tokens. The method is key-free, not reference-free: it requires
a strong paired oracle on one short-context public instance. It does not
recover keys, does not classify an unfamiliar web document, and does not
refute \citet{christ2024undetectable} or \citet{zhang2024sand}.
\end{abstract}

\noindent\textbf{Keywords:}
statistical text watermarking, SynthID-Text, paired-reference auditing,
key-free indication, empirical likelihood ratio.

\medskip
\noindent\textit{How to read this report.}
Prompt-group ranking (exploratory \textbf{36/36}, lock~A \textbf{99/100},

\section{Introduction}
\label{sec:intro}

Statistical watermarks for language models bias next-token sampling with
a secret keyed function, then test whether a finished string contains
more of that structure than chance \citep{kirchenbauer2023watermark,
aaronson2023watermark,dathathri2024synthid}. SynthID-Text is a tournament
member of that family, deployed at scale and released as a public
reference implementation
\citep{dathathri2024synthid,deepmind2024synthidcode}. Official detection
needs the instance keys. Those keys exist in the public reference code;
this report withholds them from the auditor by design. If a third party
cannot or will not use the vendor's keys, verification is an open
practical question \citep{deepmind2024issue22,gloaguen2025blackbox,wang2026ttp}.

This report asks a scoped version of that question, on one public
instance, under a strong oracle:

\begin{quote}
\emph{Given matched marked and unmarked generations from the same
prompts, and no detector keys at scoring time, can an auditor tell
whether \texttt{public-deepmind-30} is on---as a ranking of prompt
groups, and as a decision on one 128-token file?}
\end{quote}

The two grains must not be collapsed. On the measured corpora,
paired-reference group indication can be strong even when a prespecified
isolated-file threshold is uninformative. A slogan of the form
``key-free detection works'' or ``key-free detection fails'' is false
for this measurement.

\subsection{Contribution}

Independent work already asked whether a third party can detect a
sampling watermark without the vendor's keys (\Cref{sec:related}).
\citet{gloaguen2025blackbox} test a generator property with black-box
queries. \citet{wang2026ttp} verify finished strings from paired
watermarked/unwatermarked references---the closest published analog.
The increment here is a lightweight count-table likelihood-ratio reader
together with a two-grain measurement on DeepMind's public mixin: group
ranking can succeed while a prespecified isolated threshold fails.

In order:

\begin{enumerate}[leftmargin=*]
\item A paired-reference empirical log-likelihood ratio. Decision-time
inputs are finished strings. Keys, \texttt{hash\_iv}, $g$-values, and
the official score are unused.
\item A two-grain measurement on \texttt{public-deepmind-30}. Exploratory
in-domain ranking \textbf{36/36}; prospectively specified GPT-2 lock~A
\textbf{99/100}; corrected original hard-reader diagnostic \textbf{9/12}.
Isolated zero-threshold decisions on the original set are
\textbf{47/96} correct (sensitivity \textbf{25/48}).
\item Cross-generator native refitting on the same 100 prompts:
DistilGPT-2 lock~B \textbf{88/100} (one tie), Qwen2-1.5B lock~B
\textbf{95/100}. Rankpath drops more than opening poshits on both
generators (paired McNemar on GPT-2-win losses).
\item Artifact controls: a truncated-context overcount correction, an
occupancy versus observed-token split, and a key-free argmax
perturbation that returns official scores to chance at a large
rewrite cost.
\item A preregistered longer-history replication: public keys at
$\Hw=12$ ($\mathtt{ngram\_len}=13$). Official matching scores remain
above $0.55$ on all 400 marked 100-family files. Interpolate last-4
group ranking falls from lock~A \textbf{99/100} to \textbf{76/100}.
Isolated $489/800$ is a different corpus from the original-12
\textbf{47/96}.
\end{enumerate}

What this is not: key recovery; a web-crawler detector; a calibrated
isolated-file classifier; a production Gemini or Claude measurement; a
complexity-theoretic distinguisher against
\citet{christ2024undetectable}; a mixing attack against
\citet{zhang2024sand}; a new watermark construction.

The intended venue is a technical report. The work is a bounded
empirical note on one public short-context instance, not a flagship
detection result.

\paragraph{Sampling watermarks.}
\citet{kirchenbauer2023watermark} bias sampling with a keyed green list.
\citet{kuditipudi2024robust} give a distortion-free inverse-transform
construction. SynthID-Text reweights the language model's top-$\Ktop$
with keyed $g$-values \citep{dathathri2024synthid}. This repository's
\texttt{score} path calls the public \texttt{detector\_mean}; it does
not reimplement it. \citet{omidi2026synthid} analyse keyed scores. That
is not the present indicator.

\paragraph{Undetectability and strong watermarking.}
\citet{christ2024undetectable} prove cryptographic undetectability for a
stated PRF construction. \citet{zhang2024sand} prove impossibility of
\emph{strong} watermarking given a quality oracle and a mixing oracle.
This laboratory did not instantiate that scheme and did not run those
oracles. Lock~A \textbf{99/100} is not a distinguisher against their
objects. Isolated \textbf{47/96} is a different grain, not a restoration
of those theorems.

\paragraph{Stealing and public verifiability.}
\citet{jovanovic2024stealing} learn spoof/remove models from API
samples. Concurrent stealing includes \citet{wu2024bypassing} and
\citet{pang2024nfl}. We do not steal keys. \citet{duan2025pvmark} wrap
keyed detectors in a zero-knowledge proof; the detector still uses the
key. DeepMind's public-verification request remains open
\citep{deepmind2024issue22}.

\paragraph{Third-party detection.}
\citet{gloaguen2025blackbox} detect a watermarking scheme as a generator
property. SRI Lab applied those tests to a local SynthID deployment
\citep{gloaguen2024probingsynthid}. That is not scoring a finished
string against count tables. Anthropic's announced Claude mark is a
future external test \citep{anthropic2026watermarknews}; production
keys are not public, and \texttt{score} on \texttt{public-deepmind-30}
cannot read that instance.

\subsection{SynthID-Text on the public instance}

An autoregressive model supplies $P_0(x_t \mid x_{<t})$. SynthID-Text
does not insert hidden characters. It biases which token is sampled
\citep{dathathri2024synthid}.

The public reference configuration is \texttt{public-deepmind-30}:
$\mathtt{ngram\_len}=5$, hence watermark hash history $\Hw=4$; 30 public
keys; $\mathtt{context\_history\_size}=1024$. The implementation hashes
the recent context with a linear congruential generator. Trust the code
for $g$-values: 12 LCG mixes, then $(\mathrm{hash} \gg 30) \bmod 2$.
The mixin's docstring (``lowest three bits'') does not match that
implementation. $g$-values are binary.

Only the language model's top-$\Ktop$ candidates are reweighted
($\Ktop=40$; temperature $1.0$). Repeated context hashes are masked so
they do not add repeated evidence. The first $\Hw$ generated tokens
cannot form a complete \emph{official} scored 5-gram.

The official mean detector averages unmasked $g$-values of observed
tokens. Under unmarked generation from this fixed instance,
$\E[g]=1/2$ over hash outputs along the string. Distortion-freeness in
expectation over \emph{random keys} is a claim of the scheme
\citep{dathathri2024synthid}, not a theorem proved here. A deployed
instance fixes one key set.

\Cref{tab:official_12} is the keyed positive control on the original 12
prompts (first draw). The \texttt{Prompt} column is
\texttt{detector\_mean} of the prompt string itself. The prompt is not
stamped; those scores sit near $1/2$. Every marked continuation sits
well above $0.55$; unmarked continuations stay near $1/2$. The cutoff
$0.55$ is a laboratory convenience for counting keyed positives. It is
not a published DeepMind decision rule.

\subsection{The paired auditor}

\begin{definition}[Key-free paired auditor]
\label{def:auditor}
The auditor $\mathcal{A}$ has black-box access to two configurations of
the same generator and tokenizer:
\begin{enumerate}[label=(\roman*)]
\item unmarked $G_0$, producing $x^{(u)}\sim P_0(\cdot \mid p)$;
\item marked $G_w$, producing $x^{(m)}\sim P_w(\cdot \mid p)$ under a
fixed public instance.
\end{enumerate}
It holds a paired training corpus of finished strings
\[
\D_{\mathrm{train}}
= \bigl\{(p_i, x_{i,j}^{(m)}, x_{i,j}^{(u)})\bigr\}
\]
across $N$ prompt families and $M$ draws per family. It does
\emph{not} use the instance keys, \texttt{hash\_iv}, $g$-value tables,
or the official scoring oracle at decision time. The keys are public in
the reference implementation and are withheld by design. Official
\texttt{score} is a positive control that the mixin is on, not the
contribution.
\end{definition}

This is a strong oracle: a laboratory that can toggle the mixin, or a
before/after collection of matched outputs. The method is
\textbf{key-free}. It is \textbf{not reference-free} and \textbf{not
fully blind}. In this repository, \texttt{blind} means
leave-one-prompt-out on those twins.

Marked and unmarked draws are \emph{prompt-matched}, not seed-paired.
For family offset $r$ and draw $j$, marked and unmarked files use
distinct \texttt{torch.manual\_seed} values
(\Cref{sec:generation}). Do not treat a marked/unmarked pair as a
shared sampling stream.

\subsection{Two evaluation grains}

\paragraph{Task 1: prompt-group ranking.}
For a held-out prompt $p$ with $M$ marked and $M$ unmarked draws, declare
a win if
\begin{equation}
D_p
=
\frac{1}{M}\sum_{j=1}^{M} \LLR\bigl(x_{p,j}^{(m)}\bigr)
-
\frac{1}{M}\sum_{j=1}^{M} \LLR\bigl(x_{p,j}^{(u)}\bigr)
> 0.
\label{eq:ranking}
\end{equation}
Ties ($D_p=0$) are not awarded. Both means may be negative: a win then
means the unmarked group is more negative, not that any marked file is
positive.

\paragraph{Task 2: isolated-file decision.}
For one file $x$ of $T=128$ generated tokens,
\begin{equation}
\hat y(x) = \mathbf{1}\{\LLR(x)>\tau\},
\qquad \tau=0 \text{ unless named as post hoc.}
\label{eq:isolated}
\end{equation}
No twin is shown at test time. The headline isolated result uses the
prespecified $\tau=0$, not a Youden threshold \citep{youden1950index}
fit on the same stem. The primary isolated statistic is the $2\times 2$
confusion matrix and the balanced accuracy
$({\mathrm{TP}}+{\mathrm{TN}})/96$ on the original set.

The independent ranking unit is the prompt family. Leave-one-prompt-out
tables share training mass, so families are weakly dependent.
Clopper--Pearson intervals \citep{clopper1934binomial} on win counts
are descriptive under an independent Bernoulli model that the design
only approximates. File-level label-shuffle permutation $p$-values
\citep{ernst2004permutation} ignore pairing and clustering; they are
descriptive. Exact McNemar tests on discordant prompt-family signs
\citep{mcnemar1947sampling} are clustered descriptions of already-opened
scores, not a second freeze.

\paragraph{Declared operating criteria.}
The primary group endpoint is the prompt-family win count of
\eqref{eq:ranking}. The primary isolated endpoint is balanced accuracy
at the prespecified $\tau=0$, reported with the full $2\times 2$
matrix. Sensitivity, specificity, and precision are companions of that
matrix, not substitutes for it. File AUC \citep{fawcett2006roc} is a
secondary, threshold-free ranking statistic; it does not test whether
$\tau=0$ is calibrated. For abstaining readers, coverage and
conditional performance on files with $n>0$ are reported separately:
$n=0$ is not counted as a confident negative.

The 12, 36, and 100 prompt sets are designed collections, not random
draws from a stated population. Intervals describe a hypothetical
repeated-sampling process on those fixed prompts and the laboratory
generator, not inference to English at large.

\section{Method}
\label{sec:method}

\subsection{Paired generation}
\label{sec:generation}

All twins use Hugging Face generators with the public mixin.
Length is matched at 128 new tokens
(\texttt{min\_new\_tokens}=\texttt{max\_new\_tokens}). Temperature is $1.0$, top-$\Ktop=40$,
and the pad token equals EOS. Prompts are plain strings; Qwen2-Instruct
is not wrapped in a chat template. EOS does not truncate early: every
file has 128 new tokens.

Seed allocation for family offset $r$, $M=4$, base seed $s$:
marked draw $j\in\{0,1,2,3\}$ uses $s + (2M+2)r + 2j$; unmarked draw
$j$ uses one more. Marked and unmarked never share a seed.

Default Hub identifiers: \texttt{gpt2}, \texttt{distilgpt2},
\texttt{Qwen/Qwen2-1.5B-Instruct}. Hub revisions were not pinned at
generation time. \texttt{transformers==4.57.6}. SynthID-Text is the
public reference package installed with \texttt{pip install -e \ldots
--no-deps}. Exact frozen dumps and commands are in \Cref{app:artifacts}.

Corpora used in the headline tables:

\begin{itemize}[leftmargin=*]
\item Original 12 scene prompts (Grok-length: one everyday scene each),
GPT-2, 4 draws. Headline 12-LOO hard reader, after the truncated-context
recount.
\item 36 in-domain GPT-2 topics $\times$ 4 draws. Exploratory hits
reader.
\item 100 new English one-line scene prompts, disjoint as strings from
the 36, seed \texttt{20260901}. Prospective lock~A/B/C.
\item The same 100 prompts on DistilGPT-2 and Qwen2-1.5B-Instruct
(Phase~B). Native tables per generator. Lock~A interpolate was not run
on those twins.
\end{itemize}

\subsection{Empirical mean log-likelihood ratio}

Fit two next-token count tables on the training twins. Generated token
$0$ is skipped by default (no nonempty last-$\hist$ context without the
prompt). Prompt tokens are not available as context unless
\texttt{prompt-context} is named. Smoothing is Lidstone with
$\alpha=0.5$ \citep{lidstone1920note}. For a context $c$ and token $y$,
\begin{equation}
\hat P(y \mid c)
= \frac{C(c,y)+\alpha}{\sum_{y'} C(c,y') + \alpha V_{\mathrm{obs}}},
\label{eq:lidstone}
\end{equation}
where $V_{\mathrm{obs}}$ is the size of the union of next tokens observed in the marked
and unmarked training unigrams, not $|\V|$. Logs are natural. If a
context is seen in one table and unseen in the other, the unseen side
uses unigram Lidstone (hard) or Witten--Bell backoff (interpolate).

The file score is the \emph{mean} per scored position:
\begin{equation}
\LLR(x)
= \frac{1}{n}\sum_{t \in \mathcal{I}(x)}
\log \frac{\Phatm(x_t \mid c_t)}{\Phatu(x_t \mid c_t)},
\label{eq:llr}
\end{equation}
where $\mathcal{I}(x)$ are scored generated indices and
$n=|\mathcal{I}(x)|$. If $n=0$, $\LLR(x)=0$. For the headline hard
reader that assignment is a numerical convention, not an abstention
state: after skipping token 0, every 128-token file has $n>0$. Hats are
essential: the auditor never observes $P_w$. Equation~\eqref{eq:llr}
has the Neyman--Pearson likelihood-ratio form
\citep{neyman1933most}, with estimated rather than known conditionals;
it is not claimed to be an optimal test of $P_w$ versus $P_0$.

At generated index $i$, the scored context is the up-to-$\hist$ previous
\emph{generated} tokens. Window $[0{:}4)$ therefore contains indices
$\{0,1,2,3\}$; with token 0 skipped, three events remain, with context
lengths $1,2,3$ rather than a full last-4. That is why $[0{:}4)$ is an
opening measurement rather than four complete $\hist=4$ events.

Fitting stores each real suffix length $1,\ldots,\min(\hist,i)$ once.
An earlier bug stored a truncated opening $\hist$ times
(\Cref{sec:overcount}).

\subsection{Readers}
\label{sec:readers}

\paragraph{hard.}
Equation~\eqref{eq:lidstone} at the longest available context, with
unigram fallback if that key is empty. Primary original-12 diagnostic.

\paragraph{hits.}
Score a position only if the exact last-$\hist$ context was observed in
\emph{both} training piles; else skip it. Exploratory 36-topic ranking
reader.

\paragraph{poshits.}
Namespace counts by position bucket $i // B$. Lock~B uses
\texttt{fit-prefix}${}=4$ and $B=1$, so each of the first four generated
tokens has its own table.

\paragraph{postokhits.}
As poshits, but a position contributes only if the observed next token
occurred under that namespaced context (occupancy-free). Positions may
abstain. If every position abstains, $n=0$ and $\LLR=0$; coverage and
conditional performance are reported separately and zeros are not
treated as confident negatives.

\paragraph{interpolate (lock~A).}
Witten--Bell interpolation \citep{witten1991zero}. Let $n_c$ be the
count mass of context $c$ and $r_c$ the number of distinct next tokens.
If $c$ is unseen or $n_c=0$, recurse to the shortened suffix. Otherwise
\[
\hat P(y\mid c)
=
\frac{n_c}{n_c+r_c}\cdot \frac{C(c,y)}{n_c}
+
\frac{r_c}{n_c+r_c}\cdot \hat P(y\mid c^{-}),
\]
with $c^{-}$ the context with the oldest token dropped, and with
Lidstone unigram at the empty context. Probabilities are clipped below
at $10^{-18}$ before the log. Unseen next tokens are therefore scored by
backoff: interpolate nested recall is not occupancy-free recall.

\paragraph{rankpath (lock~C).}
Replace token identity with a five-symbol unmarked-LM rank alphabet on
the unmarked top-$\Ktop=40$:
symbol 0 if the chosen token misses top-$\Ktop$;
1 if rank 1 (argmax);
2 if ranks 2--3;
3 if ranks 4--10;
4 if ranks 11--40.
Those five bins partition $\{0\}\cup\{1,\ldots,40\}$. Isolated rankpath
skips generated token 0 (no unmarked-LM context without the prompt), so
\texttt{fit-prefix}${}=4$ yields three rank symbols. Rankpath uses
observed-token backoff on the symbol sequence
(\texttt{include\_first} on symbols). It needs the unmarked language
model at scoring time and still does not use keys.

Hash pooling is a laboratory splitmix of token ids. It is not SynthID's
secret hash and is not used in the headline tables.

\paragraph{Occupancy.}
If a context is seen in training but the evaluation next token is not,
add-$\alpha$ still assigns a nonzero log ratio from the two occupancy
denominators. That mass is not an observed-token hit.
\texttt{postokhits} removes it.

\subsection{Windows}
\label{sec:windows}

Slice $[a{:}b)$ denotes generated indices $i$ with $a\le i<b$. Two
implementations exist.

\begin{itemize}[leftmargin=*]
\item \emph{Reindexed.} The slice is copied out as a new string. Token 0
of that substring is skipped, and contexts do not include tokens before
$a$. The first committed H2 dump used this behaviour.
\item \emph{Absolute.} The full string is retained. Only indices in
$[a{:}b)$ are averaged; preceding tokens remain as context. Later
probes refuse to reindex a window as a new sequence.
\end{itemize}

H2 reports both. The reindexed dump is not overwritten.

\subsection{Leave-one-family-out}
\label{sec:loo}

For each family $p$, tables are fit on all other families and the $2M$
held-out files of $p$ are scored. That is the evaluation topology of
\textbf{9/12}, \textbf{36/36}, \textbf{99/100}, Distil
\textbf{88/100}, and Qwen \textbf{95/100}. Pseudocode is
\Cref{alg:loo}.

This is a frozen \emph{algorithm and evaluation protocol}, not a frozen fitted detector.
Lock~A \textbf{99/100} is leave-one-family-out on the 100 new families after the reader definition was locked.
It is not application of tables fit on the original 12.

\paragraph{Nested Youden is post hoc.}
A later readout chooses, for family $p$, a Youden threshold on the other
families' already-held-out scores \citep{youden1950index}. Those other
scores were produced by models that trained on $p$: when family $q\neq p$
was scored, its leave-one-out tables included $p$. The threshold for $p$
therefore sees mass from $p$. The procedure is a threshold nest, not
second-level nested cross-validation, and is not an unbiased held-out
classifier (\Cref{fig:youden}). Isolated headlines use $\tau=0$. Nested
Youden counts stay out of detector-performance comparisons.

\subsection{A named non-inferiority margin (demoted)}
\label{sec:margin}

A laboratory robustness switch declares a ranking win when
$\bar\LLR_{\mathrm{m}}+0.02>\bar\LLR_{\mathrm{u}}$, i.e.\ $D_p>-0.02$.
On the original 12 this moves ferry-queue and yields 10/12. That rule is
not the Bernoulli trial of \Cref{eq:ranking}. Under a symmetric
no-effect distribution, $P(D_p>-0.02)$ exceeds $1/2$, so a
Clopper--Pearson interval around 10/12 that excludes $1/2$ does not
establish above-chance performance under the margin. The $0.02$
tolerance was not a pre-registered primary endpoint of lock~A. It is
reported only as a descriptive sensitivity analysis and is absent from
the abstract.

\section{Why a Fixed Key Can Leave a Trace}
\label{sec:math}

The following is a mechanism sketch, not a tight theorem. Empirical
$\LLR$ uses $\Phatm$ and $\Phatu$, not $P_w$.

Let $G$ be a random key and $g^*$ the deployed instance. Distortion-freeness
in expectation over keys does not imply equality for one reused key:
\begin{equation}
\E_{G}[P_{G}(\cdot\mid c)] = P_0(\cdot\mid c)
\quad\not\Rightarrow\quad
P_{g^*}(\cdot\mid c) = P_0(\cdot\mid c).
\label{eq:fixed}
\end{equation}
Tournament sampling on a fixed $g$-table reweights top-$\Ktop$ in a
context-dependent way. Repeated draws from the same prompt reuse short
contexts ($\Hw=4$ on this mixin). Matched samples can therefore produce
$\Phatm\neq\Phatu$ on occupied contexts without revealing the key.

Conditionally on the fitted tables, the within-family contrast satisfies
\[
\mathrm{Var}\!\left(D_p \mid \Phatm,\Phatu\right)
=
O(1/M)
\]
if the $2M$ draws are independent with finite per-file variance. That
statement is not unconditional: all held-out scores share estimated
tables. We do not claim an exponential Hoeffding bound, and we do not
claim that isolated $T=128$ classification is impossible in general.

\paragraph{Scaling hypotheses, not production facts.}
As $\Hw$ grows, exact held-out context overlap should fall and sample
demand should rise. As $\Ktop$ grows, observations per context-token
outcome spread more thinly. Lower-order Witten--Bell backoff may retain
a coarser signal that is no longer a reused 4-gram footprint. Which
failure mode dominates on a longer-context or structurally different
mixin is untested. That is the primary external-validity experiment
(\Cref{sec:next}).

Christ et al.\ and Zhang et al.\ apply to different constructions and
oracles (\Cref{sec:related}). Isolated chance accuracy at $\tau=0$ is
compatible with a weak single-file test. Population ranking of matched
twins is outside their single-challenge games as stated. Neither
sentence is a theorem about tournament sampling in their sense.

\section{Ablations and Mechanistic Perturbation}
\label{sec:ablations}

\subsection{Truncated-context overcount}
\label{sec:overcount}

Early logs stored every order $1,\ldots,\hist$ even when fewer tokens existed,
so a one-token opening was counted $\hist$ times. After storing each
real suffix once, hard last-4 ranking moved from 10/12 to \textbf{9/12}
and isolated sensitivity from 29/48 to \textbf{25/48}. Prompt ranking
survived. Pre-fix JSON is historical.

\subsection{Occupancy versus observed tokens}

On a 4-token new-topic gate, poshits isolated $\tau=0$ is 39/48 vs.\
41/48. Occupancy-free \texttt{postokhits} is 16/48, with decided
precision 1.000 when $n_{\mathrm{used}}>0$. Isolated observed-token
recall on named opening readers equals train opening-atom overlap. That
identity does not create a denser isolated-file detector. Comparing
marked recall alone with 25/48 is not a sufficient evaluation rule: a
low-recall, high-specificity abstaining reader is a different operating
point.

\subsection{H2 windows}

H2 asked whether lock~A window $[0{:}4)$ outranks $[16{:}32)$ on the 100
GPT-2 families. Reindexed: $[0{:}4)$ \textbf{99/100} (AUC $0.885$),
$[16{:}32)$ \textbf{89/100} (AUC $0.689$). Absolute-history:
$[0{:}4)$ \textbf{99/100} (AUC $0.885$), $[16{:}32)$ \textbf{87/100}
(AUC $0.695$). Opening still outranks mid-file in-family. Post-open
paired McNemar on the absolute windows is $86/13/1/0$ (both / opening
only / mid only / neither);
$P(X\ge 13\mid \mathrm{Bin}(14,1/2))\approx 0.00092$. That is not a
second freeze.

Out-of-family, the same interpolate tables are not front-loaded on
Grok-length files (reindexed $[0{:}4)$ is 7/12; tails 9/12).

\subsection{Argmax perturbation}
\label{sec:scrub}

Tournament sampling only reweights the unmarked top-$\Ktop$. Snapping
each generated token to the unmarked argmax, using original prefixes,
is a key-free \emph{mechanistic perturbation}. It needs the unmarked
language model, not the keys. About 60--90 of 128 tokens flip. On all 48
marked original-12 files, official mean moves $0.6216\to 0.4994$. The
procedure is not a fluent rewrite, not self-consistent regeneration,
and not a practical removal attack.

\section{Limitations}
\label{sec:limits}

The public instance is a short-context ($\Hw=4$) demo, not a proprietary
production key. Group ranking needs matched draws per prompt. Isolated
classification of one 128-token file at $\tau=0$ is chance-like on the
original set. File AUC $0.590$ is weak and was not a confirmatory
endpoint.

The auditor is strong: marked and unmarked twins, finished strings, a
toggleable mixin. Closest published finished-string analog is
\citet{wang2026ttp}; this repository does not reimplement TTP-Detect on
a shared corpus. \Cref{tab:compare} quotes their published proxy and
A100 costs against this laboratory's committed count-table dump. That
is a resource contrast, not a shared-benchmark TPR.

Nested Youden is not fully nested. The $0.02$ margin is not a valid
chance test. Prompt sets are designed, not sampled from a stated
population. Lock~A \textbf{99/100} is prospectively specified
leave-one-family-out, not evaluation of one frozen fitted table on a
later corpus. Distil keyed 70/100 is a first-draw official comparison,
not the four-draw key-free endpoint. Isolated balanced accuracy at
$\tau=0$ is not distinguishable from chance under a prompt-clustered
sign-flip.

How count-table coverage scales with longer watermark history is
partly measured: $\Hw=12$ attenuates group ranking from lock~A
\textbf{99/100} to \textbf{76/100} on the same 100 prompt strings
(different twins). Occupancy of exact 4-grams was not decoded on that
dump. Production Gemini and Anthropic keys were not measured.
Multi-key replication of the public mixin is not started. Isolated-file
research is not finished.

\section{Conclusion}
\label{sec:conclusion}

With matched labeled marked/unmarked reference generations and no
detector keys at scoring time, empirical count-table auditors rank
marked prompt-group means above unmarked means in 36/36 exploratory
in-domain families and 99/100 prospectively generated same-register
GPT-2 families under a predeclared leave-one-family-out protocol. The
corrected original hard-reader diagnostic is 9/12. On the original 96
individual files, the prespecified zero threshold yields 25/48
sensitivity, 22/48 specificity, precision 25/51, and 47/96 correct
decisions, while threshold-free file AUC is 0.590. Prompt-clustered
permutation of balanced accuracy is consistent with chance. Official
keyed leftover detection remains 20/20 where the empirical reader is
chance.

These results establish paired-reference indication at the group grain
for one public SynthID-Text instance. They do not establish calibrated
standalone indication on an unfamiliar file, a universal key-free
detector, key recovery, or a refutation of
\citet{christ2024undetectable} or \citet{zhang2024sand}. A preregistered
lengthening of the public mixin to $\Hw=12$ (freeze SHA \texttt{b70986d})
drops interpolate last-4 ranking from lock~A \textbf{99/100} to
\textbf{76/100} on 100 one-liners, while official matching scores remain
above $0.55$ on all 400 marked files. The original-12 readout is
\textbf{6/12} (underpowered; \texttt{prompt\_sign\_p}$=0.247$). Isolated
$\tau=0$ on those 12 is $52/96$. The original-12 hard matrix remains
\textbf{25/48} sensitivity and \textbf{47/96} correct. A different local
mixin remains unopened. The 100-family readout is not Distil/Qwen
Phase~B.

Code and frozen JSON:
\url{https://github.com/jensabrahamsson/text-watermark-laboratory}.

\paragraph{Control keys.}
Text sampled with \texttt{control-shuffled-30} scores near $0.50$ on the
public keys (mean of 48 file means $0.501$) and near $0.62$ on the
matching control keys ($0.624$). Key-free opening poshits trained on
public twins assign $\LLR>0$ to $0/48$ control files. Public vs.\
control still ranks $12/12$ (AUC $0.906$). The reader is
instance-specific without recovering keys.
