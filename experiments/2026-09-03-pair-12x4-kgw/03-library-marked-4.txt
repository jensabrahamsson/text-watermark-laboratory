This is a story about the changes to the history of Toronto over five decades. One of the reasons I write about them, though, is that we can no longer get the same perspective on that particular century without losing the depth at which we can see each other. We can not learn to appreciate each other without learning that history does not have anything to do with what we see. The first two chapters of the first novel, which are so familiar we find them, offer an opening, not the same sort of view; the second is a story about the changes.
